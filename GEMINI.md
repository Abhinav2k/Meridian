# Workspace Guidelines

## Visual Verification & Screenshots
- **No Autonomous Screenshotting**: Do not trigger screenshots (`take_screenshot.trigger`) or capture and view screenshots autonomously. The user directly observes the running interface on their desktop.
- **Confirm Before Capturing**: Always ask the user if a screenshot is required before attempting any capture.
- **User Instruction Required**: Only capture or inspect screenshots when the user explicitly requests or approves doing so.

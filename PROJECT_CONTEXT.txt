MERIDIAN DYNAMIC ISLAND — AGENT HANDOFF CONTEXT
===============================================

User goal
---------
Build a luxury dynamic island desktop overlay (Meridian) that lives directly on the
desktop, not inside a normal framed window. It should feel live, with the desktop
visible through it, blur/refraction, and an iPhone / visionOS liquid glass appearance.

User preference / working rule
------------------------------
If a quality gap is technically doable, implement it instead of presenting it
as a limitation. Continue iterating and testing. Do not leave known doable work
as a caveat.

Current project
---------------
Meridian.csproj:
   - TargetFramework: net10.0-windows10.0.19041.0
   - OutputType: WinExe
   - AssemblyName: Meridian
   - RootNamespace: Meridian
   - ApplicationHighDpiMode: PerMonitorV2
   - UseWindowsForms: true
   - UseWPF: false
   - AllowUnsafeBlocks: true
   - Nullable and implicit usings enabled.

Program.cs:
   - STAThread entry point.
   - ApplicationConfiguration.Initialize().
   - Manages --settings switch and normal dynamic island overlay execution.
   - Automatically registers desktop shortcuts (Meridian Settings.lnk, Meridian Island.lnk).

Overlay behavior
----------------
OverlayForm is:
   - Borderless, topmost, hidden from taskbar and Alt+Tab.
   - Positioned permanently at the topmost center of the screen with top padding.
   - Dynamic spawn & morph animation: Spawns as a tiny liquid droplet, drops down with an elastic spring, and fluidly blooms/morphs into the compact clock pill or expands into full media / weather / system cards.
   - Escape closes the app.
   - Space or Left-Click on the pill replays the spawn and morph animation.
   - S key saves a high-resolution PNG snapshot (meridian-snapshot.png).
   - WmNcHitTest returns HTTRANSPARENT outside the curved pill so underlying apps and browser tabs remain fully clickable and interactive.

Commands
--------

    dotnet run
